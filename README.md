## Supabase
No `script.js`, preencha:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

A página tenta inserir cliques na tabela `leads`. Se o Supabase não estiver configurado, o site continua funcionando e os botões do WhatsApp continuam abrindo normalmente.

### SQL opcional para criar a tabela `leads`
```sql
create table public.leads (
  id bigint generated by default as identity primary key,
  event_type text not null,
  source text,
  page text,
  user_agent text,
  created_at timestamptz default now()
);

alter table public.leads enable row level security;

create policy "allow anonymous lead inserts"
on public.leads
for insert
to anon
with check (true);
```

> Para um projeto real, refine as políticas RLS antes de colocar dados sensíveis nessa tabela.
